# تشغيل البوت على هاتف أندرويد

هذا الحل يتفادى حجب يوتيوب لأن هاتفك يستخدم IP منزلي/موبايل حقيقي (غير محظور)،
على عكس خوادم ريندر (مراكز بيانات).

## المتطلبات
- هاتف أندرويد + إنترنت (واي فاي أو شريحة)

## الخطوات

### 1) ثبّت تطبيق Termux
نزّله من F-Droid (وليس من Google Play لأن نسخة Play قديمة):
- فتح `https://f-droid.org` في المتصفح
- ثبّت تطبيق F-Droid
- من داخل F-Droid ابحث عن **Termux** وثبّته

### 2) افتح Termux واكتب الأمر التالي (يأخذ بضع دقائق)
```bash
curl -sL https://raw.githubusercontent.com/Guelma-Dev/audio-cut-bot/main/termux/install.sh -o install.sh && bash install.sh
```

### 3) انسخ ملف البوت إلى الهاتف
- من أي تطبيق/متجر ملفات على الهاتف، احفظ ملف `main.py` في مجلد التنزيلات
  (تحمّله من https://raw.githubusercontent.com/Guelma-Dev/audio-cut-bot/main/main.py)
- في Termux اكتب:
```bash
termux-setup-storage
cp ~/storage/downloads/main.py ~/audiobot/main.py
```

### 4) شغّل البوت
```bash
bash run.sh
```
سيبدأ البوت فوراً. **أبقِ Termux مفتوحاً** وستجد البوت يعمل.

### 5) إيقاف البوت
- في نافذة Termux: اضغط `Ctrl + C`
- أو اسحب التطبيق من قائمة التطبيقات الأخيرة

### ملاحظات مهمة
- البوت يعمل فقط **طالما كانت نافذة Termux مفتوحة** — هذا مقصود لتتمكن من إيقافه متى شئت.
- عند السفر/الإغلاق، البوت يتوقف، وعند رجوعك تشغّله مجدداً بنفس الأمر.
- يمكنك إيقاف قفل شاشة الهاتف عن Termux (من إعدادات البطارية) حتى لا يغلق الخلفية.
